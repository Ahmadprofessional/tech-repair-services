# CCTV Generic Illustrative Images

This directory stores generic illustrative visual assets for the CCTV Installation landing page (`/services/cctv-installation`).

## Image Files & Recommended Specs
- **Aspect Ratio:** 3:2 or 16:9 (e.g. 600x400px or 1200x800px)
- **Format:** `.webp` (optimized, compressed)
- **Note:** These are generic equipment and feature illustrations. Under no circumstances should they be labeled or captioned as the client's own installation work or customer premises.

### Required Files:
1. `dome-camera.webp` - Generic dome camera hardware illustration (discreet ceiling/soffit mounting, infrared night vision).
2. `bullet-camera.webp` - Generic bullet camera hardware illustration (visible perimeter/driveway mount, 2K/4K resolution).
3. `doorbell-camera.webp` - Generic smart doorbell camera illustration (front door entrance, smartphone alert integration).
4. `nvr-recorder.webp` - Generic NVR / DVR recording unit illustration (central hub, local hard drive storage).
5. `phone-live-view.webp` - Generic smartphone app interface illustration (multi-camera live feed and playback).
